# Zine Visual System for Decks

Use this reference to translate the two Zeejay0 zine skills from single posters into coherent slide systems. Read the original skill instructions when invoking either engine; this reference does not replace them.

## Shared Deck Grammar

Preserve the signature relationship:

```text
truth or semantic evidence → source-derived abstraction → one structural hue → tactile boundary → active quiet space
```

Across the deck, lock:

- one paper/background family;
- one neutral ink system with no more than two neutral values per slide;
- one exact high-chroma accent hue unless brand constraints require more;
- one anchor geometry or relationship;
- one primary illustration grammar per slide;
- one torn-edge or isolated-contour logic per compartment;
- a controlled density rhythm: anchor, dense, breathing, anchor.

Do not make every slide look like the same poster. Preserve the system while varying silhouette, scale, position, and quiet-space distribution.

## Gathered Scene Translation

Use `scenes-gathered-zine-v1-3` when photography remains visible.

- Keep the photographic anchor truthful and protect the semantic minimum.
- Preserve one key spatial invariant such as horizon, path, facing direction, or overlap.
- Let illustration affect a broad field while most of that field remains unprinted.
- Compress 60–80% of descriptive detail; for foliage and micro-texture, remove roughly 85–95%.
- Use a visible narrow hand-torn fibrous edge at the main photo-to-paper handoff.
- Derive the chromatic system from the scene and make it pass a structural removal test.
- Add no typography inside generated art by default. Keep presentation copy native and editable.

## Distilled Scene Translation

Use `scene-distillation-zine-v1-3` when no source pixels should remain.

- Identify the semantic nucleus and preserve two to four source anchors.
- State one expressive proposition and one central tension.
- Transform one source-derived object, gesture, or relation into the central metaphor.
- Remove roughly 65–90% of descriptive detail.
- Favor 68–85% quiet paper and one active cluster, corrected by visual weight.
- Choose one primary grammar: cut-paper mass, dry-print silhouette, broken contour, rhythm field, fragment stack, or orbit/drift.
- Use Standard Accent Mode unless the exact trigger `单色块模式` is present.
- Keep generated typography out of the art unless it is conceptually essential; deck titles and labels should remain native whenever possible.
- Never reproduce, embed, crop, collage, trace, or retain photographic pixels or photorealistic regions from the reference.

## Hybrid Slides

A hybrid slide needs a legible relationship:

- evidence → interpretation;
- place → memory;
- object → metaphor;
- before → after;
- surface → underlying structure.

Keep gathered and distilled scenes in separate compartments. Link them with the visual anchor, one shared axis or gesture, and the same accent hue. Do not overlap them merely for texture.

## Anchor State Examples

| Narrative state | Anchor behavior |
|---|---|
| Opening | Appears as a compact clue with generous quiet space |
| Context | Extends into a seam, path, or horizon that organizes evidence |
| Tension | Fragments, narrows, becomes enclosed, or shifts temperature/value |
| Resolution | Reconnects, opens, or becomes a stable field |
| Close | Returns in its simplest recognizable form with the final takeaway |

## Hard Avoids

Avoid generic mood decoration, full-scene tracing, dense botanical filigree, polished vector cartoons, arbitrary geometry, random dots, detached color blocks, sticker outlines, clean digital masks, uniform deckled frames, heavy shadows, curled paper, glossy mockups, multiple competing bright hues, dense scrapbooking, commercial CTA hierarchy, and watermarks.

Preserve privacy and source handling from the original zine skills. Send only required source images and final prompts to an image-generation service. Do not browse, upload elsewhere, or save user photos beyond the task unless the user asks.
