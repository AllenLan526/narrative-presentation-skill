# Credits and Sources

This file is intentionally separate from the poster artwork.

## Design-method provenance

- The visual-anchor, quiet-space, compartment, spacing, and source-first planning methods adapt the repository's [`zine-anchor-deck`](../../skill/SKILL.md) skill.
- The reusable package and demo were produced with the [`create-editable-zine-poster`](../../skills/create-editable-zine-poster/SKILL.md) skill in this repository.
- Canva's generation route was tested, but design generation is disabled for the connected Canva team. The delivered demo therefore uses semantic HTML/CSS as its measured rendering source, a parallel modular SVG for vector interchange, and a browser-printed vector PDF for other editors.
